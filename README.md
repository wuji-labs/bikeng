## 写给谁

- 正要开公司、刚开了公司、或已经在坑里的经营者；
- 给经营者搭把手的会计、律师、代办、平台运营者；
- 任何想看清中国小企业真实处境的人。

## 编例与免责

- 文中「原声」为众多真实声音的写实合成，不指向任何具名个人或企业；
- 内容以 2026 年初为基准，政策与平台规则随时间变化，执行前请核对现行规定；
- 两份文档均为公益性通用信息，**不构成法律或税务意见**，涉具体处置请咨询持证专业人士；
- 文中对灰色做法的记录是为了让痛被看见，不是对任何违规做法的指引或背书。
